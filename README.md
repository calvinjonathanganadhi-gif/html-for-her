# html-for-her
🌸 A Little Something for Joanna

A small interactive webpage made with HTML, CSS, and JavaScript as a personal way to ask someone out. ♡

The website is designed primarily for mobile viewing, while also supporting desktop and landscape orientations.

✨ Features

* 💌 Animated opening page with a personalized greeting
* 🌸 Animated flower decorations
* ✨ Floating particles and petals
* 📸 Scrapbook-style memory page
* 💭 Scrollable list of favorite things
* 💐 Animated transition/reveal pages
* 🎀 Handwritten-note-style final question
* 💗 Interactive answer buttons
* 🎉 A final celebration page
* 📱 Responsive mobile design
* 🖥️ Landscape and desktop support
* ♿ Reduced-motion support for users who prefer less animation

🌷 Adding Your Own Flowers

The flower decorations use transparent PNG images.

Place your flower images inside the flowers folder and make sure their filenames match the paths in index.html.

For example:

flowers/flower1.png
flowers/flower2.png
flowers/flower3.png

The JavaScript randomly selects from these images and places them around the page.

Tip: Transparent PNGs work best. Flower heads don’t need stems.

🚀 Running Locally

No framework or installation is required.

Simply open:

index.html

in a browser.

For the best testing experience, use Chrome DevTools’ mobile device emulator.

Shortcut:

Ctrl + Shift + M

Try testing both portrait and landscape orientations.

🌐 GitHub Pages

This project can be hosted for free using GitHub Pages.

1. Create a GitHub repository.
2. Upload index.html.
3. Upload your photos.
4. Upload the flowers folder and its PNGs.
5. Open the repository’s Settings.
6. Find Pages.
7. Set the deployment source to your main branch.
8. Save.

GitHub will provide a website URL once the deployment finishes.
